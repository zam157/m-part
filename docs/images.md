# Provider 图片缩放

封面资料中的 `coverUrl` 始终保留源地址。列表、播放队列、本地缓存、路由参数和一起听协议不写入某个显示位置的缩略图地址；只在展示时生成 URL，避免小图进入缓存后再被放大。

## 通用接口

Provider 可选实现 `getImageUrl(url, options)`，返回转换后的图片 URL。`options` 包含 `usage`、物理像素宽高 `width` / `height` 和 `fit`（`cover` / `contain`）。方法必须同步、无网络请求，不修改输入数据；不支持的域名、路径或签名地址返回原地址。可按 `usage` 单独调整压缩、尺寸档位或格式，不在组件中识别音源或拼接 CDN 参数。

`@m-part/music/image` 提供 `imageUrl(provider, url, usage, density?)` 和 `imageSrcSet(...)`，统一补全 HTTPS、设置默认尺寸与 1x / 2x 候选。默认 CSS 像素如下；2x 请求宽高翻倍，Provider 仍可限制在 CDN 支持的尺寸内。

| usage | 默认尺寸 | 使用位置 |
| --- | --- | --- |
| `queue` | 40×40 | 普通及展开播放队列 |
| `player` | 48×48 | 底部播放器 |
| `list` | 48×48 | 歌单 / 专辑 / 歌手详情中的曲目或专辑列表 |
| `card` | 480×270 | 首页推荐、搜索卡片 |
| `collection` | 320×320 | 平台 / 本地歌单卡片 |
| `detail` | 160×160 | 歌单 / 专辑 / 歌手详情头图 |
| `expanded` | 480×480 | 展开播放器主封面 |
| `background` | 96×96，仅 1x | 展开播放器模糊背景 |
| `media-session` | 512×512 | 系统媒体封面 |

`packages/player/src/components/ProviderImage/` 转发原生图片属性并设置 `src` / `srcset`，保留原有布局、懒加载和 referrer policy。浏览器自行选择像素密度；候选地址相同时不输出 `srcset`。缩略图失败后，当前图片回退一次原地址，不持续重试；曲目 / 音源 / 用途改变时重新尝试缩略图。空地址不生成 `src=""` 请求。展开播放器大图和背景按需懒加载，模糊背景不申请高分辨率版本。

本地歌单可能混合多个平台：每个曲目使用自己的 `provider`，封面卡片与详情头图使用首曲所属平台，不能套用当前搜索或平台歌单所选音源。

## 平台适配

- BiliBili：仅处理 `*.hdslb.com/bfs/` 的图片路径，使用 `@宽w_高h_1c.webp`，先替换已有处理后缀，避免重复追加。未知查询参数或签名地址保留原样。
- 网易云：仅处理 `p数字.music.126.net` 图片 CDN，设置 / 替换 `param=宽y高`，保留其他参数及 fragment；不处理 `m数字.music.126.net` 音频。
- QQ 音乐：专辑 / 歌手的 `y.gtimg.cn/music/photo_new/T001或T002…` 路径改写 `R宽x高`；已识别的 `qpic.y.qq.com` / `p.qpic.cn` 的 `/music_cover/…/尺寸` 改写末尾档位。按 90 / 150 / 300 / 500 / 800 档位向上选择，最大 800；未知 CDN 路径保留原样。

适配实现在 `packages/music/src/utils/provider-images.ts`，各 Provider 通过 `getImageUrl` 注册。新增音源可自行提供不同实现；通用组件不需要改变。

## 验证（2026-10-30）

实际 CDN 样本：BiliBili 原图 1439×900、167407 B，40×40 WebP 为 610 B，80×80 为 1702 B；网易云原图 2000×2000、796101 B，40×40 为 918 B，80×80 为 2378 B；QQ 专辑 300×300 为 26391 B，90×90 为 5881 B，另验证 500×500 版本及歌单 300→150 档位。数据来自本次样本，不代表所有封面压缩率。

扩展中的搜索卡片、队列、底部 / 展开播放器，以及包含三平台曲目的临时本地歌单，均确认使用各自用途的缩略图和 2x 候选。自动测试覆盖地址替换、域名边界、签名 / 未知地址回退、用途参数传递、属性响应更新与加载失败回退。
