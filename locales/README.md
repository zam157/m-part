## i18n

> **当前状态：未接入。** 前端已从 Vue 3 重构为 Solid 2，本次重构中完全移除了 i18n（`@intlify/unplugin-vue-i18n` / `vue-i18n` 依赖与调用均已删除），界面文案暂为硬编码。
> 本目录下的语言文件被保留作为翻译资源备份，需重新选型（例如 `@solid-primitives/i18n` 或自建方案）后再接入。

This directory is to serve your locale translation files.

If you are using VS Code, [`i18n Ally`](https://github.com/lokalise/i18n-ally) is recommended to make the i18n experience better.
